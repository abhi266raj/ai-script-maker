# System Requirements Specification: macOS Standalone Executable & Packaging Roadmap

> **Current Milestone (v1.3):** Manual Packaging Script & Local DMG Verification  
> **Future Milestone (v2.0):** Automated GitHub Actions CI/CD Release Pipeline  
> **Feature Branch:** `feature/v1.3-macos-standalone-package`  
> **Target:** Hindi Reel Studio macOS Application (`.app` & `.dmg`)  
> **Distribution:** Standalone double-clickable Mac desktop app inside an Apple Disk Image (`.dmg`).

---

## 1. Executive Summary & Phased Roadmap

Currently, running Hindi Reel Studio requires cloning the repository, creating a virtual environment, installing dependencies, and running terminal commands.

To ensure stability, packaging is divided across two major milestones:

### 🎯 Milestone v1.3 (Current Scope)
1. **Local Build Script (`scripts/build_macos_app.sh`)**: Creates a 100% self-contained macOS `.app` bundle and packages it into an installer disk image (`.dmg`).
2. **Native Desktop Window**: Runs as a standalone macOS desktop application (Dock icon, native window via Cocoa/WKWebView), **not a web browser tab**.
3. **Manual Verification & Release**: Build and thoroughly test the `.dmg` locally across initial releases to guarantee zero missing libraries, port conflicts, or asset paths. Manually attach to GitHub Releases.

### 🚀 Milestone v2.0 (Next Scope)
1. **Automated GitHub Actions CI/CD (`.github/workflows/release_package.yml`)**: Once the packaging script and runtime are battle-tested and proven completely stable over manual releases, automate the build and release asset uploads directly in GitHub on tag pushes (`v*`).

## 2. Functional Requirements (User Stories)

### FR-1: Automated Local Build Script (`scripts/build_macos_app.sh`)
- Provide a single executable script:
  ```bash
  ./scripts/build_macos_app.sh
  ```
- The script must:
  - Verify macOS host environment and tools (`create-dmg` or `hdiutil`, `pyinstaller`).
  - Bundle Python 3, Streamlit, Pydantic, Beautiful Soup, and all project assets (`prompts/`, `core/`, `agents/`, `tools/`, `macos/`).
  - Generate a clean standalone bundle: `dist/Hindi Reel Studio.app`.
  - Package the bundle into an Apple Disk Image: `dist/Hindi-Reel-Studio-v1.3.0-macOS.dmg`.
  - Include drag-and-drop `/Applications` symlink inside the `.dmg` for native macOS installation.

### FR-2: Standalone Desktop Window Architecture (Native App, Not a Web App)
- The app must run as a **native desktop application window** (`StudioWindow` WKWebView Cocoa app or PyInstaller desktop window), **NOT as a website or browser tab**.
- Zero dependency on external browser installation (no Chrome/Brave/Edge browser launch requirement).
- App stays in the macOS Dock with its own icon, window management, and native macOS menu bar.
- Fully self-contained inside the `.app` bundle within the `.dmg`.
- Completely isolated from system Python: zero Python or terminal requirement for end-users.

### FR-3: Phased Release Strategy (Manual Verification First ➔ Automated CI/CD)
- **Phase 1 (Immediate / Initial Releases - v1.3.x): Manual Build & Verification**
  - Release engineer builds the package locally via `./scripts/build_macos_app.sh`.
  - Thoroughly test the generated DMG on local macOS: install to `/Applications`, test clean startup, verify window and offline assets.
  - Manually create GitHub Release and upload `Hindi-Reel-Studio-v1.3.0-macOS.dmg` and `.zip`.
  - Validate across the first few releases to guarantee runtime stability, zero missing dependencies, and smooth user onboarding.
- **Phase 2 (Subsequent Releases - Once Workflow Is Battle-Tested): GitHub Actions Automation**
  - Provide `.github/workflows/release_package.yml` configured with `workflow_dispatch` (manual trigger) first, then automated tag push (`v*`).
  - GitHub runner executes the verified `./scripts/build_macos_app.sh` and attaches artifacts automatically only after the manual process has proven 100% reliable.

### FR-4: Clean macOS App Bundle Metadata
- `CFBundleIdentifier`: `com.hindireel.studio`
- `CFBundleShortVersionString`: `1.3.0`
- `CFBundleVersion`: `1.3.0`
- High-resolution multi-size app icon (`AppIcon.icns`).
- Minimum macOS version supported: macOS 12.0 (Monterey) through macOS 15+ (Sequoia) on Apple Silicon (M1/M2/M3/M4) and Intel.

## 3. Technical Architecture & File Layout

```
├── .github/
│   └── workflows/
│       └── release_package.yml        # Automated CI/CD release builder
├── scripts/
│   ├── build_macos_app.sh            # Main packaging script (PyInstaller + hdiutil/dmg)
│   └── run_standalone.py             # Entrypoint wrapper for Streamlit headless boot
├── Hindi Reel Studio.app/             # Pre-configured app bundle template
│   └── Contents/
│       ├── Info.plist                # App bundle metadata
│       ├── MacOS/                    # Standalone executable binary
│       └── Resources/                # AppIcon.icns
└── dist/                             # Build artifacts destination (gitignored)
    ├── Hindi Reel Studio.app
    └── Hindi-Reel-Studio-v1.3.0-macOS.dmg
```

## 4. Verification & Testing Criteria

1. **Local Build Test:**
   - Run `./scripts/build_macos_app.sh` locally.
   - Verify `dist/Hindi-Reel-Studio-v1.3.0-macOS.dmg` is created and mounts cleanly.
2. **Double-Click Launch Test:**
   - Drag `Hindi Reel Studio.app` to `/Applications` or run from disk.
   - Verify the studio interface loads immediately without terminal windows.
3. **CI/CD Dry-Run Test:**
   - Validate YAML syntax of `.github/workflows/release_package.yml`.
   - Verify release upload asset mapping.
