## User Review Required

> [!IMPORTANT]
> **Native Window Strategy**: The existing `app_runner` binary (compiled from `macos/StudioWindow.swift`) currently expects `.venv/bin/streamlit` in the parent directory of the `.app`. For a truly standalone bundle, the build script will:
> 1. Use **PyInstaller** to freeze the entire Python runtime + Streamlit + all deps into a single-folder bundle inside the `.app`.
> 2. Create a new **`scripts/run_standalone.py`** entrypoint that boots Streamlit headlessly from the frozen bundle.
> 3. **Recompile `StudioWindow.swift`** so `app_runner` looks for the frozen Streamlit inside `Contents/Resources/` instead of `../.venv/`.

> [!IMPORTANT]
> **`create-dmg` not found** — the build script will attempt to use `create-dmg` (Homebrew) first, and fall back to raw `hdiutil` if unavailable. Both produce valid `.dmg` files; `create-dmg` adds the pretty drag-to-Applications background.

> [!WARNING]
> **Code Signing**: The current `.app` has a `_CodeSignature/CodeResources` file. The build script will **ad-hoc sign** (`codesign -s -`) the rebuilt bundle. Full Developer ID signing is out of scope for v1.3 and can be added later.

## Proposed Changes

### Build Scripts (`scripts/`)

#### [NEW] `scripts/build_macos_app.sh`

The main packaging script. Single command to produce the `.dmg`. Five phases:

```
Phase 1: VERIFY   — check python3, swiftc, install pyinstaller if missing
Phase 2: FREEZE   — PyInstaller bundles Python + Streamlit + all deps + project assets
Phase 3: ASSEMBLE — build .app with frozen runtime, recompile Swift, write Info.plist
Phase 4: DMG      — create-dmg (or hdiutil fallback) with /Applications symlink
Phase 5: SUMMARY  — print artifact paths and sizes
```

```bash
#!/usr/bin/env bash
# build_macos_app.sh — Hindi Reel Studio macOS standalone packager (v1.3)
set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
PROJECT_DIR="$(dirname "$SCRIPT_DIR")"
APP_NAME="Hindi Reel Studio"
APP_BUNDLE="dist/${APP_NAME}.app"
DMG_NAME="Hindi-Reel-Studio-v1.3.0-macOS.dmg"
VERSION="1.3.0"
IDENTIFIER="com.hindireel.studio"

cd "$PROJECT_DIR"

# ─── Phase 1: Verify tools ───
echo "━━━ 1/5  VERIFY — checking build tools ━━━"
command -v python3   || { echo "❌ python3 not found"; exit 1; }
command -v swiftc    || { echo "❌ swiftc not found (install Xcode CLI tools)"; exit 1; }

if ! .venv/bin/python3 -c "import PyInstaller" 2>/dev/null; then
    echo "📦 Installing PyInstaller..."
    .venv/bin/pip install pyinstaller
fi
echo "✅ All build tools present"

# ─── Phase 2: PyInstaller freeze ───
echo "━━━ 2/5  FREEZE — bundling Python + Streamlit + deps ━━━"
rm -rf build dist

.venv/bin/pyinstaller \
    --noconfirm \
    --name "hindi_reel_studio" \
    --add-data "prompts:prompts" \
    --add-data "core:core" \
    --add-data "agents:agents" \
    --add-data "tools:tools" \
    --add-data ".streamlit:_streamlit" \
    --add-data "app.py:." \
    --hidden-import streamlit \
    --hidden-import pydantic \
    --hidden-import httpx \
    --hidden-import feedparser \
    --hidden-import bs4 \
    --collect-all streamlit \
    scripts/run_standalone.py

echo "✅ PyInstaller bundle created"

# ─── Phase 3: Assemble .app bundle ───
echo "━━━ 3/5  ASSEMBLE — building ${APP_NAME}.app ━━━"
rm -rf "${APP_BUNDLE}"
mkdir -p "${APP_BUNDLE}/Contents/MacOS"
mkdir -p "${APP_BUNDLE}/Contents/Resources"

# Copy the frozen bundle into Resources
cp -R "dist/run_standalone/" "${APP_BUNDLE}/Contents/Resources/runtime"

# Compile the native Cocoa window (updated to find runtime inside .app)
swiftc -O -o "${APP_BUNDLE}/Contents/MacOS/app_runner" \
    macos/StudioWindow.swift \
    -framework Cocoa -framework WebKit

# Copy icon
cp "Hindi Reel Studio.app/Contents/Resources/AppIcon.icns" \
   "${APP_BUNDLE}/Contents/Resources/AppIcon.icns"

# Write Info.plist
cat > "${APP_BUNDLE}/Contents/Info.plist" << PLIST
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN"
    "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>CFBundleExecutable</key>
    <string>app_runner</string>
    <key>CFBundleIconFile</key>
    <string>AppIcon.icns</string>
    <key>CFBundleIdentifier</key>
    <string>${IDENTIFIER}</string>
    <key>CFBundleName</key>
    <string>${APP_NAME}</string>
    <key>CFBundleDisplayName</key>
    <string>${APP_NAME}</string>
    <key>CFBundlePackageType</key>
    <string>APPL</string>
    <key>CFBundleShortVersionString</key>
    <string>${VERSION}</string>
    <key>CFBundleVersion</key>
    <string>${VERSION}</string>
    <key>LSMinimumSystemVersion</key>
    <string>12.0</string>
    <key>NSHighResolutionCapable</key>
    <true/>
    <key>NSAppTransportSecurity</key>
    <dict>
        <key>NSAllowsLocalNetworking</key>
        <true/>
    </dict>
    <key>LSApplicationCategoryType</key>
    <string>public.app-category.productivity</string>
</dict>
</plist>
PLIST

# Ad-hoc code sign
codesign --force --deep -s - "${APP_BUNDLE}"
echo "✅ ${APP_NAME}.app assembled and signed (ad-hoc)"

# ─── Phase 4: Create DMG ───
echo "━━━ 4/5  DMG — packaging disk image ━━━"
rm -f "dist/${DMG_NAME}"

if command -v create-dmg &>/dev/null; then
    create-dmg \
        --volname "${APP_NAME}" \
        --window-pos 200 120 \
        --window-size 600 400 \
        --icon "${APP_NAME}.app" 150 190 \
        --app-drop-link 450 190 \
        "dist/${DMG_NAME}" \
        "${APP_BUNDLE}"
else
    echo "ℹ️  create-dmg not found — using hdiutil (install via: brew install create-dmg)"
    STAGING="dist/dmg_staging"
    rm -rf "$STAGING"
    mkdir -p "$STAGING"
    cp -R "${APP_BUNDLE}" "$STAGING/"
    ln -s /Applications "$STAGING/Applications"
    hdiutil create -volname "${APP_NAME}" \
        -srcfolder "$STAGING" \
        -ov -format UDZO \
        "dist/${DMG_NAME}"
    rm -rf "$STAGING"
fi

echo "✅ dist/${DMG_NAME} created"

# ─── Phase 5: Summary ───
echo "━━━ 5/5  DONE ━━━"
echo ""
echo "📦 Artifacts:"
ls -lh "dist/${DMG_NAME}"
ls -lhd "${APP_BUNDLE}"
echo ""
echo "🚀 To test: open dist/${DMG_NAME}"
```

#### [NEW] `scripts/run_standalone.py`

PyInstaller entrypoint — boots Streamlit headlessly from within the frozen bundle.

```python
#!/usr/bin/env python3
"""Entrypoint for the PyInstaller-frozen Hindi Reel Studio.

Launches Streamlit in headless mode, serving app.py on 127.0.0.1:8501.
The native Cocoa window (app_runner) connects to this local server.
"""
import os
import sys

def _setup_paths():
    """Configure paths so frozen Streamlit finds all project modules."""
    if getattr(sys, 'frozen', False):
        bundle_dir = sys._MEIPASS
    else:
        bundle_dir = os.path.dirname(os.path.abspath(__file__))
    
    if bundle_dir not in sys.path:
        sys.path.insert(0, bundle_dir)
    
    streamlit_config = os.path.join(bundle_dir, '_streamlit')
    if os.path.isdir(streamlit_config):
        os.environ['STREAMLIT_CONFIG_DIR'] = streamlit_config
    
    return bundle_dir

def main():
    bundle_dir = _setup_paths()
    app_py = os.path.join(bundle_dir, 'app.py')
    
    from streamlit.web import cli as st_cli
    sys.argv = [
        'streamlit', 'run', app_py,
        '--server.headless', 'true',
        '--server.address', '127.0.0.1',
        '--server.port', '8501',
    ]
    st_cli.main()

if __name__ == '__main__':
    main()
```
