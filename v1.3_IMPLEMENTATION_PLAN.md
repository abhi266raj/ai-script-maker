## Goal

Implement the v1.3 packaging milestone for Hindi Reel Studio: a **self-contained macOS `.app` bundle** packaged into a **`.dmg` installer**, built via a single `./scripts/build_macos_app.sh` script. The build script supports **two distinct variants** — **Dev** and **Release** — that can coexist side-by-side on the same Mac with different icons, bundle identifiers, ports, and names.

## Proposed Changes

### Build Scripts (`scripts/`)

#### [NEW] `scripts/build_macos_app.sh`

Main packaging script with `--dev` flag for variant selection. Six phases:

```
Phase 1: VERIFY   — check python3, swiftc, install pyinstaller if missing
Phase 2: ICON     — generate AppIcon-Dev.icns if --dev (skip for release)
Phase 3: FREEZE   — PyInstaller bundles Python + Streamlit + all deps + project assets
Phase 4: ASSEMBLE — build .app with frozen runtime, recompile Swift, write Info.plist
Phase 5: DMG      — create-dmg (or hdiutil fallback) with /Applications symlink
Phase 6: SUMMARY  — print artifact paths and sizes
```

Key variant logic:
```bash
DEV_MODE=false
if [[ "${1:-}" == "--dev" ]]; then DEV_MODE=true; fi

if $DEV_MODE; then
    APP_NAME="Hindi Reel Studio DEV"
    IDENTIFIER="com.hindireel.studio.dev"
    DMG_NAME="Hindi-Reel-Studio-DEV-v${VERSION}-macOS.dmg"
    ICON_FILE="AppIcon-Dev.icns"
    SERVER_PORT="8502"
else
    APP_NAME="Hindi Reel Studio"
    IDENTIFIER="com.hindireel.studio"
    DMG_NAME="Hindi-Reel-Studio-v${VERSION}-macOS.dmg"
    ICON_FILE="AppIcon.icns"
    SERVER_PORT="8501"
fi
```

#### [NEW] `scripts/run_standalone.py`

PyInstaller entrypoint — boots Streamlit headlessly. Reads port from `HRS_PORT` environment variable (set by the native Cocoa wrapper) to support Dev/Release isolation.

```python
def main():
    bundle_dir = _setup_paths()
    app_py = os.path.join(bundle_dir, 'app.py')
    port = os.environ.get('HRS_PORT', '8501')
    
    from streamlit.web import cli as st_cli
    sys.argv = [
        'streamlit', 'run', app_py,
        '--server.headless', 'true',
        '--server.address', '127.0.0.1',
        '--server.port', port,
    ]
    st_cli.main()
```

#### [NEW] `scripts/generate_dev_icon.py`

Generates `AppIcon-Dev.icns` by compositing a red "DEV" banner onto each icon size from `AppIcon.iconset/`. Uses Pillow if available, falls back to a plain copy.

### Native App Wrapper (`macos/`)

#### [MODIFY] `macos/StudioWindow.swift`

Two key changes:
1. **Read port and title from `Info.plist`** via `Bundle.main.object(forInfoDictionaryKey:)` — this lets the same Swift code serve both variants.
2. **Launch frozen runtime** from `Contents/Resources/runtime/run_standalone` instead of `.venv/bin/streamlit`.

```swift
// Port from Info.plist (8501 for Release, 8502 for Dev)
private let port: Int = {
    Bundle.main.object(forInfoDictionaryKey: "HRSServerPort") as? Int ?? 8501
}()

// Window title from Info.plist
private var windowTitle: String = {
    Bundle.main.object(forInfoDictionaryKey: "CFBundleDisplayName") as? String
        ?? "Hindi Reel Studio"
}()
```
