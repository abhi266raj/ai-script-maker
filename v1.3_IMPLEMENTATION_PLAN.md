## Goal

Implement the v1.3 packaging milestone for Hindi Reel Studio: a **self-contained macOS `.app` bundle** packaged into a **`.dmg` installer**, built via a single `./scripts/build_macos_app.sh` script. The build script supports **two distinct variants** — **Dev** and **Release** — that can coexist side-by-side on the same Mac with different icons, bundle identifiers, ports, and names.

## Remaining Proposed Changes

### Build Scripts (`scripts/`)

#### [NEW] `scripts/build_macos_app.sh`

Main packaging script with `--dev` / `--release` flags. Six phases:

```
Phase 1: VERIFY   — check python3, swiftc, install pyinstaller if missing
Phase 2: ICON     — generate AppIcon-Dev.icns if --dev (skip for release)
Phase 3: FREEZE   — PyInstaller bundles Python + Streamlit + all deps + project assets
Phase 4: ASSEMBLE — build .app with frozen runtime, recompile Swift, write Info.plist
Phase 5: DMG      — create-dmg (or hdiutil fallback) with /Applications symlink
Phase 6: SUMMARY  — print artifact paths and sizes
```

---

#### [NEW] `scripts/run_standalone.py`

PyInstaller entrypoint — boots Streamlit headlessly. Reads port from `HRS_PORT` environment variable.

## Verification Plan

### Automated Tests
```bash
# 1. Existing test suite
.venv/bin/python3 -m unittest discover tests

# 2. Build Release variant
./scripts/build_macos_app.sh --release
test -f "dist/Hindi-Reel-Studio-v1.3.0-macOS.dmg"

# 3. Build Dev variant
./scripts/build_macos_app.sh --dev
test -f "dist/Hindi-Reel-Studio-DEV-v1.3.0-macOS.dmg"

# 4. Verify different bundle identifiers
/usr/libexec/PlistBuddy -c "Print CFBundleIdentifier" \
    "dist/Hindi Reel Studio.app/Contents/Info.plist"
# → com.hindireel.studio

/usr/libexec/PlistBuddy -c "Print CFBundleIdentifier" \
    "dist/Hindi Reel Studio DEV.app/Contents/Info.plist"
# → com.hindireel.studio.dev
```

### Manual Verification
1. Install **both** DMGs to `/Applications` — verify separate entries.
2. Launch both simultaneously — verify separate Dock icons, separate windows, no port conflict.
3. Verify Dev icon shows red "DEV" banner; Release has clean icon.
4. Verify window titles: "Hindi Reel Studio" vs "Hindi Reel Studio DEV".
5. No terminal window pops up on launch.
